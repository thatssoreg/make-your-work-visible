# Open and use the workshop

Open `index.html` in a full browser, not an attachment preview. Use the arrow keys or Back/Next. Contents opens the slide list. Read all displays the whole session as a scrollable reference. Full screen uses the browser's fullscreen feature where allowed.

In practice contains the activities. Field guide contains the references and AI prompts. Artifact contains the portfolio collection, writing kit, and readings. Return to the session preserves the slide you left.

The app has no timer or presenter mode. Keep `docs/print/run-sheet.pdf` beside the laptop. `docs/print/facilitator-guide.pdf` contains expanded cues. The student worksheet is optional and downloadable within the field guide.

Before class, try the Figma tabs, README before/after, profile/website tabs, an activity, and a template download. Open external examples while signed out. Test on the actual teaching laptop/projector.

Students can participate in their own notes without a GitHub account, AI subscription, or working Wi-Fi. External services require internet. No new account should become a prerequisite to making progress during the workshop.
