# Before students arrive

**Open `index.html` in a full browser.** Save a copy on the teaching laptop rather than depending on a download preview or a live link. The browser's attachment preview may not execute JavaScript.

Give students the actual HTML file, the same approved hosted URL you tested, or the worksheet. A local path on the presenter's laptop is not a distributable link. Students can use the same file on their own devices; their timers and cards are independent.

Use the one-page run sheet beside the laptop. Use the full facilitator PDF when you want the one-line speaker cue, actions, and transition for each screen. Give each student three Post-it notes and access to a pen. The two-page worksheet is optional.

## Five-minute laptop preflight

1. Open the HTML. Advance to screen 3, choose a starting condition, and reveal a nudge and an example.
2. Start and reset a timer. Check a Markdown download and, when convenient, a work-card export.
3. Open Artifact, filter a portfolio perspective, open a card, and return to the session.
4. Check the Figma/CSIS examples and the two GitHub profiles while signed out, or use the embedded descriptions when access fails.
5. Use Present to hide personal work titles and route selections. Confirm the projector is readable at the chosen zoom and select the 40- or 45-minute setting.

## In the room

Have everyone select one piece of work by minute five. Use the shared examples to teach a move, not to make everyone adopt the same project. Before the individual application, point students back to their original note.

When a learner is stuck, begin with a question. Offer the nudge or worked example when it helps. The next exercise defaults to the task without extra help, and the final reader test has no help panel.

Use local notes when account access is slow. A project plan must remain a plan, not become a fabricated accomplishment. A student can participate without public posting, a paid tool, or revealing private work.

Technical correctness belongs with course staff, a technical peer, official documentation, or a provider-authored learning resource. Reggie facilitates scoping, explanation, reflection, and feedback.
