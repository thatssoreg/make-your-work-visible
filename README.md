# Make Your Work Visible

A scaffolded GitHub and portfolio workshop by Reggie Leonard, **SDS Career Services, UVA School of Data Science**.

This repository is being initialized with the approved workshop release. The workshop follows one student-selected project, assignment, question, or job task through fluency, legibility, and reach. Artifact supplies the companion portfolio collection and writing kit.

The release uses static HTML, CSS, and JavaScript. It has no model API calls, API keys, backend, or student-account connection. Student work remains in the learner's own files and tools.

The implementation and release instructions will be committed together after the build checks finish. No repository visibility setting or hosting configuration is changed by this initialization.
